# ПЕПЕЛЬНЫЙ ПРЕДЕЛ — 3D roguelike bullet hell

Браузерная фэнтези-игра: 20 волн нежити, лавка артефактов между волнами, мини-боссы и случайный финальный Владыка Предела. Работает целиком в браузере на three.js (WebGL), без бэкенда — подходит для GitHub Pages. Рекорды и настройки хранятся в `localStorage`.

## Возможности

- **20 волн.** Каждая длиннее и сложнее предыдущей и приводит новых врагов. После волны — выбор даров за набранные уровни и сундуки, затем лавка.
- **Привал у костра:** после волны — 3D-лобби, где герой сидит у огня, а костяной меняла Мортимер продаёт артефакты (26 штук, четыре редкости) и комментирует покупки.
- **Боссы:** на 10-й волне — Костяной Воевода, на 15-й — Ледяной Исполин, на 20-й — случайно один из трёх Владык:
  - **Пепельный Дракон** — огненное дыхание конусом, метеоритный дождь, пикирование через поле;
  - **Владыка Бездны** — вращающиеся лучи, телепорт, призыв бесов, самонаводящиеся сферы;
  - **Иерарх Тлена** — кристаллы душ делают его неуязвимым, пока их не разбить; поднимает мёртвых.
- **14 типов врагов с разной тактикой:** прислужники и черепа давят числом, лучники держат дистанцию, бесы делают рывок, духи-камикадзе взрываются, метатели накрывают зоной, шаманы лечат своих, некроманты призывают, вихри телепортируются, орки таранят, големы раскалываются, великаны бьют по земле.
- **Читаемость:** пуль немного, а сильные атаки телеграфируются на земле — кругами, линиями и конусами, которые заполняются перед ударом.
- **5 героев с разным стилем боя и своими путями развития:**
  - **Бранд** — ближний бой секирой: дуговые удары, накопление ярости, вихрь. Пути: Ярость / Пламя / Вихрь.
  - **Эйра** — арбалет: настоящие стрелы, тяжёлый болт каждым 4-м выстрелом, метки, капканы. Пути: Залп / Снайпер / Капканы.
  - **Альдерон** — цепная молния, грозовая туча над головой, остановка времени. Пути: Цепи / Буря / Время.
  - **Готфрид** — меч и щит: щит блокирует снаряды спереди, волны света, освящённая земля. Пути: Свет / Твердыня / Освящение.
  - **Лиорэ** — некромант: убитые враги встают скелетами-союзниками, армия растёт. Пути: Легион / Рыцари / Души.
  - У каждого пути есть «вершина» — сильный дар, который появляется после двух даров этого пути.
- **Три оружия у каждого героя** на выбор перед походом, у каждого свой стиль: секира, парные или метательные топоры; арбалет, самострел или ножи; посох молний, шаровые молнии или гримуар; меч и щит, двуручный меч или шипастый щит; стрелы души, ритуальный кинжал или склянки чумы.
- **Таинства** — редкие дары за уровень, которые меняют саму атаку: Трезубец (атака в три стороны), Двуликий (удар за спину), Длань титана или Шквал (редкие мощные или частые слабые удары), Цепная реакция, Звездопад, Чёрная воронка, Раскол, Поступь великана, Кровавая цена. Вокруг них строится билд.
- **Кузня у костра:** за золото оружие и броня улучшаются в одном из шести направлений (оружие — Пламя, Стужа, Гроза, Кровь, Сила, Ветер; броня — Твердь, Тень, Шипы, Руны, Жизнь). Редкость растёт со ступенями, а три ступени одного направления открывают легендарное свойство. Над прилавком видны главные характеристики героя, прирост после покупки подсвечивается. Ещё в лавке есть две случайные диковины; если выкуплено всё, переброс бесплатный.
- **Сложность растёт:** каждый уровень требует заметно больше опыта, а враги с каждой волной крепче, сильнее и чуть быстрее.
- **Звук:** процедурная оркестровая музыка (хор, арфа, лютня, виолончель, медь, барабаны, реверберация) с разными темами для меню, боя, босса и привала; отдельные звуки для каждого вида атаки.
- **Пауза** с вкладками: характеристики и умения героя, полученные дары и купленные артефакты с описаниями, настройки.
- Автоматическая стрельба только по видимым врагам в пределах дальности оружия, звук выключается клавишей M, 3D-модели с анимациями (KayKit, Quaternius — CC0).

## Управление

| Действие | Клавиши |
| --- | --- |
| Движение | WASD / стрелки |
| Стрельба и прицел | автоматически |
| Способность | Space / E / ПКМ |
| Фокус (медленно + видно хитбокс) | Shift |
| Выбор дара / переброс | 1, 2, 3 / R |
| Лавка: следующая волна | Enter |
| Пауза | Esc / P |
| Выключить / включить звук | M |

## Запуск локально

ES-модули и загрузка моделей не работают через `file://`, нужен любой статический сервер:

```bash
python3 -m http.server 8000
```

и открыть http://localhost:8000. Three.js подключается с CDN jsdelivr, поэтому нужен интернет.

## Публикация на GitHub Pages

1. Создать репозиторий на GitHub и запушить в ветку `main`.
2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Workflow `.github/workflows/pages.yml` сам опубликует игру (вместе с папкой `assets`) при каждом пуше в `main`. Адрес будет вида `https://<логин>.github.io/<репозиторий>/`.

## Структура

```
index.html            разметка HUD и экранов, importmap для three.js
css/style.css         стили интерфейса
assets/models/        3D-модели (glb, meshopt) — см. assets/CREDITS.md
js/main.js            загрузка моделей и игровой цикл
js/assets.js          загрузка glTF, склейка частей моделей
js/render3d.js        3D-сцена: мир, персонажи, анимации, свет, эффекты
js/preview.js         3D-превью героев на экране выбора
js/game.js            логика: игрок, снаряды, столкновения, опыт, спавн
js/characters.js      герои: характеристики, оружие, пути развития
js/heroes.js          уникальные боевые механики героев
js/enemies.js         враги, волны, мини-боссы и финальные боссы
js/shop.js            диковины лавки и цены
js/forge.js           кузня: улучшение оружия и брони
js/upgrades.js        дары, редкости и дары путей
js/ui.js              меню, HUD, выбор даров, пауза, итоги
js/audio.js           процедурный звук и музыка (WebAudio)
js/particles.js       частицы и числа урона
js/sprites.js         текстура земли
js/input.js           клавиатура, мышь, сенсорный джойстик
```
