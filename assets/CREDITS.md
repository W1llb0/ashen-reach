# Источники 3D-моделей

Все модели распространяются по лицензии **CC0 1.0 (Public Domain)**: можно использовать в любых проектах, включая коммерческие, без указания авторства. Указываем авторов из уважения.

| Что | Автор | Источник |
| --- | --- | --- |
| Герои (Barbarian, Knight, Mage, Rogue, Rogue_Hooded) и общие анимации | Kay Lousberg — KayKit Adventurers 1.0 | https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0 |
| Скелеты (Minion, Rogue, Mage, Warrior) | Kay Lousberg — KayKit Skeletons 1.0 | https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Skeletons-1.0 |
| Надгробия, фонари, свечи, деревья, кости, столбы (`decor/`) | Kay Lousberg — KayKit Halloween Bits 1.0 | https://github.com/KayKit-Game-Assets/KayKit-Halloween-Bits-1.0 |
| Чудовища (Ghost, GhostSkull, BlueDemon, Demon, Goleling, Yeti, DragonEvolved) | Quaternius — Ultimate Monsters Bundle | https://poly.pizza/bundle/Ultimate-Monsters-Bundle-5oyGWAmOB6 |

Модели пережаты с помощью `@gltf-transform` (meshopt-сжатие, удалены неиспользуемые анимации). Анимации KayKit вынесены в общий файл `kaykit_anims.glb`, потому что у всех персонажей KayKit один и тот же скелет.
